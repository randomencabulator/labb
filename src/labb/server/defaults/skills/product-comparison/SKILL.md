# Product comparison

## Steps

1. **Get the need.** Budget, country (for prices and availability), what it's for, and must-haves. If one of these really changes the answer and you can't guess it, ask once; otherwise assume and say what you assumed.
2. **Shortlist 3-5 candidates** from independent reviews and tests (outlets that test hands-on, measured benchmarks, long-term owner reports). Not from the makers' or shops' own rankings.
3. **Collect the facts** for each: key specs that matter for the need, current price from 1-2 shops (with the date), and the main strengths and weaknesses reviewers agree on.
4. **Check for red flags**: recalls, common faults in owner reviews, a model about to be replaced, sponsored "reviews".
5. **Recommend.** One best pick for the need, plus a budget pick and an upgrade pick when they make sense.

## Format

```
## Best for <need>: <product>
<2-3 sentences why.>

| | <A> | <B> | <C> |
|---|---|---|---|
| Price (<shop>, <date>) | | | |
| <spec that matters> | | | |
| Best at | | | |
| Weak at | | | |

**Budget pick:** ... **Upgrade pick:** ...

**Sources:** [review](url), [review](url), ...
```

Prices change: always give the date and the shop. Say when a review is old or for an earlier model.
